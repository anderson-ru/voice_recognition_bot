
 ## Telegram Voice & VideoNote Bot

Telegram-бот, который распознаёт голосовые и видео-сообщения в Telegram, преобразует их в текст, а также может озвучивать произвольный текст.

 ## 📌 Возможности
- Поддержка голосовых сообщений (voice)
- Поддержка видео-сообщений (видеокружочки / video_note)
- Распознавание речи с помощью модели Whisper
- Озвучка текста с помощью gTTS

## 🚀 Быстрый старт

1. Установите зависимости:
<br/>`pip install -r requirements.txt`

2. Задайте переменную окружения с токеном Telegram:
<br/>`export TELEGRAM_API_TOKEN="your_bot_token_here"`

3. Запустите бота:
<br/>`python recognition_bot.py`

 ## 💡 Примеры использования

* Отправьте голосовое сообщение — бот пришлёт текст.
* Отправьте видеокружок — бот также его распознает.
* Команда `/say Привет, мир!` — бот озвучит фразу.

## 🧪 История версий

* `experiments/echo_bot_.py` — отправляет обратно все типы сообщений.
* `recognition_bot.py` — текущая версия с распознаванием и озвучкой.
